# Security policy

This repo is a learning demo, not a production service. I still want to hear about security problems, so that learners don't copy them into their own projects.

## Report a vulnerability

**Please don't open a public issue for a security problem.** Report it privately instead:

1. Open the [private vulnerability report form](https://github.com/jonahandersson/jatechstore-mcp-hosted-agents-dotnet-demo/security/advisories/new).
2. Describe the problem, how to reproduce it, and which file or setting is affected.

Only you and I can see the report while we work on it. Please don't include real keys, tokens or personal data.

## What's in scope

- The code and Bicep templates on the `main` branch
- Anything in this repo's guidance that could lead someone to build something insecure

## What's out of scope

- The known demo shortcuts listed under [Security notes](README.md#security-notes), such as booking requests kept in memory
- Your own deployment of this code, which you're responsible for securing
- Vulnerabilities in Azure, Microsoft Foundry or other third-party products. Please report those to their owners

Thank you for helping keep this demo safe for everyone learning from it.
